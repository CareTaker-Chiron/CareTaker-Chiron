# Contributing to Caretaker Chiron

Thank you for your interest in contributing.

Caretaker Chiron is an early-stage open-source project. Contributions should help make system exploration understandable, safe, reliable, and technically powerful.

## Before contributing

- Read the **README** and project architecture documentation.
- Check existing issues and pull requests.
- Open an issue before starting major features or architectural changes.
- Keep changes focused and explain the reasoning behind them.

## Development principles

## Keep operating-system-specific functionality behind platform adapters.

## Keep the core modular and testable. ## Never silently elevate privileges. ## Do not introduce arbitrary AI-generated command execution. ## Ground system explanations in observable evidence. ## Document platform-specific limitations. ## Prefer small, reviewable pull requests.

## Pull requests

Please include:

- A clear description of the change.
- The motivation and relevant issue.
- Testing performed.
- Screenshots for meaningful UI changes.
- Any platform-specific considerations.

## Code quality

Run relevant formatting, linting, type checks, and tests before submitting.

We appreciate thoughtful contributions, constructive feedback, and respectful collaboration.
