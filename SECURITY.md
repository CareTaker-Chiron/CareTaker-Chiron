# Security Policy

## Project status

Caretaker Chiron is in early development. It is not yet recommended for production or security-critical environments.

## Reporting a vulnerability

Please do not publish sensitive vulnerability details in public issues.

Use GitHub's private vulnerability reporting feature if it is enabled for this repository. Otherwise, contact the repository maintainers privately through an appropriate verified channel.

Include:

- A description of the vulnerability.
- Steps to reproduce it.
- Potential impact.
- Relevant logs or proof of concept, if safe to share.

## Security principles

Caretaker Chiron intends to:

- Minimize unnecessary privileges.
- Make privileged inspection explicit.
- Avoid arbitrary command execution by AI components.
- Keep sensitive system information local by default.
- Make optional cloud data handling transparent.
- Validate data crossing application boundaries.

Security reports are appreciated. Please allow maintainers reasonable time to investigate before public disclosure.
